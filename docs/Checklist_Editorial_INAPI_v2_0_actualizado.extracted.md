Cómo leer este documento
Cada tarea del PTD se asocia a uno o más indicadores del instrumento IQ Web. El código se presenta en notación dual cuando el indicador existe en ambos instrumentos: código del instrumento de Sitios web / código del instrumento de Servicios digitales transaccionales (por ejemplo, 1.1.2 / 5.1.2). Cuando un indicador es exclusivo de uno de los dos instrumentos, se indica expresamente. Las preguntas de chequeo listadas bajo cada tarea son las que el equipo editorial debe verificar como parte del checklist editorial antes o después de publicar o modificar el contenido o componente correspondiente.
